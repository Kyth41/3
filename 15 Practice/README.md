# Задание 1 — картотека студентов

Консольное приложение на Java: собственный односвязный список.

- `Student` — узел с именем, возрастом и ссылкой на следующий узел; ввод и вывод данных.
- `StudentList` — создание пустого списка, добавление, удаление и вывод по номеру, вывод всех записей, очистка, `isEmpty`.
- `Tester` — точка входа и текстовое меню с проверкой ввода.

Нумерация записей начинается с 1. После удаления номера пересчитываются.
Запись и чтение файла в задании необязательны и не реализованы.

## Запуск (JDK 8 или новее)

Из папки `15 Practice`:

```sh
mkdir -p /tmp/practice15-classes
javac -encoding UTF-8 -d /tmp/practice15-classes Tester.java
java -cp /tmp/practice15-classes Tester
```
